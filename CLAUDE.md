# Graph RAG Learning Lab

## Goal
User is learning to build a graph-based RAG system for relational (multi-hop) questions.
Focus: understanding system components and design tradeoffs, NOT writing lots of code.

- Stage 1: PoC (small, local, prove graph beats vector RAG on relational questions)
- Stage 2: Real-world scenario (entity resolution, hybrid retrieval, eval, ops)

Full roadmap and progress: see `plan.md`.

## How to work with the user
- **Ask questions one at a time, always multiple choice** (use the AskUserQuestion tool). Never batch several questions in one message.
- Explain concepts first (what, why, tradeoffs), then show minimal code only when it helps understanding.
- Keep code minimal and runnable; no frameworks or abstractions unless a concept requires them.
- After each step, update the progress checkboxes in `plan.md`.
- Compare against plain vector RAG where it teaches something.
